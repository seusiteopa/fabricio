# Vecorion — Site Institucional

Site institucional da Vecorion, construído com Next.js (App Router), React, TypeScript e Tailwind CSS.

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse http://localhost:3000

## Build de produção

```bash
npm run build
npm run start
```

## Deploy

Este projeto está pronto para deploy na Netlify (`netlify.toml` já configurado com `@netlify/plugin-nextjs`). Basta conectar o repositório ou rodar `netlify deploy`.
